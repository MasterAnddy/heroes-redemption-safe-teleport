# SafeTeleport Live：即時 F6 工具

這個版本供遊戲已經啟動、角色目前卡住時使用。它不修改磁碟上的 `GameAssembly.dll`，而是在遊戲程序記憶體中安裝可回滾的暫時鉤子。

## 需求

- Windows x64
- .NET 8 Runtime
- 工具與遊戲使用相同的 Windows 權限層級
- `GameAssembly.dll` 必須符合 `manifest.json` 記錄的 SHA-256

## 操作

1. 遊戲進入地圖後執行 `Start-SafeTeleport.cmd`。
2. 切回遊戲使用下列按鍵：
   - **F6**：返回 F7 錨點；尚未保存時使用該場景的已知出生點，未知場景則依序嘗試附近位置。
   - **F7**：保存目前位置。
   - **F8**：清除保存的位置。
   - **F12**：還原入口字節並退出；確認沒有執行中的鉤子後會釋放配置，否則由遊戲程序結束時回收，遊戲仍繼續運行。

熱鍵只在遊戲窗口位於前台時響應。瞬移同時清除 `Rigidbody2D` 速度。

如果工具異常退出但遊戲仍在運行，執行：

```powershell
.\Rollback.ps1
```

回滾只處理帶有本工具魔數與版本標記的鉤子；入口屬於其他工具時會停止覆蓋。

此工具包含版本鎖定的函式偏移。遊戲更新後先核對新版本，不要直接沿用舊設定。
